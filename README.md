# Layan GTK Theme All Color

An enhanced fork of the **Layan GTK Theme**, featuring additional color options, extra features, and various bug fixes.

---

## 📌 About This Repository

This repository is a fork of the original **Layan GTK Theme**. Its goal is to bring additional features and a wider range of color options to the original project, as well as fix several bugs identified over time.

The original project continues to be actively developed; this fork aims to bring together extra color palettes and improvements requested by the community.

> **Note:** All credit for the original design, structure, and source files of the theme goes to the original developer, **vinceliuice**.

---

## ✨ What's Different in This Fork?

* 🎨 Additional color options and new variants
* 🐛 Fixes for several known visual/functional bugs
* 🔧 Minor improvements and compatibility updates

## Manual Installation

1. Cloning Repository
```bash
git clone --depth 1 https://github.com/satellaos-official/Layan-gtk-theme-all-color.git "$HOME/Layan-gtk-theme-all-color"
```
   
2. Installation for User

```bash
bash $HOME/Layan-gtk-theme-all-color/install.sh -u
```

3. Installation for System

```bash
sudo bash $HOME/Layan-gtk-theme-all-color/install.sh -s
```

4. Installation for /etc/skel

```bash
sudo bash $HOME/Layan-gtk-theme-all-color/install.sh -a
```
